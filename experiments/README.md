# Experiments

Organized by date. Each folder follows the naming convention:
```
YYYY-MM-DD_short_description/
```

## Experiment Template

When creating a new experiment folder, include:
- `README.md` — Hypothesis, methodology, results summary
- `code/` — Scripts and notebooks
- `results/` — Output data, metrics, plots
- `notes.md` — Observations during the experiment, ideas for next steps
